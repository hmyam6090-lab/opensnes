# Temmie battle

An Undertale-style encounter with Temmie for the SNES, written in C on OpenSNES.

```bash
make            # builds my-game.sfc
make test       # runs the luna manifests in test/
```

## Controls

| Where | Keys |
|---|---|
| Menu | LEFT/RIGHT to move, A to confirm |
| Sub-menus | UP/DOWN (ACT), LEFT/RIGHT (Yes/No), A to confirm, B to go back |
| Text | A skips the typing, then A again continues |
| Dodging | D-pad moves the SOUL |
| End screen | START plays again |
| Debug (`GAME_DEBUG`) | in the menu: SELECT toggles Temmie Flakes, L cycles the forced attack (RANDOM / TALL / ANNOYED / ARM), R drops HP to 1; during an attack: START ends it |

## Layout

| File | Role |
|---|---|
| `main.c` | boot and the main loop |
| `src/battle.c` | the state machine: menu, ACT, MERCY, narration, speech, dodge, end |
| `src/attacks.c` | attack A (tall Temmie), its annoyed variant, attack B (the arm) |
| `src/content.c` | **every line of text and every attack tunable** |
| `src/config.h` | build switches, player numbers, screen layout |
| `src/textbox.c` | typewriter text with word wrap |
| `src/platform.c` | the only file that drives video and input through the SDK |
| `src/sound.c` | sound effects (audio module) and the music hook |
| `src/sprite_layout.c/.h` | generated by `tools/build_sprites.py`: every image as a metasprite |

## The attacks

- **Tall Temmie (A).** The `tall` image (head and body) stands on four
  wobbly legs. She walks left and right on her own, trying to make a leg
  catch you. Each walk goes to a random spot at a random speed, with a
  pause in between, and some walks are feints that turn around half way.
  You stay safe by following her inside the cage between her inner legs.
  Her fastest walk (`speed_max`) is a little slower than the SOUL, so you
  can keep up. Body and legs hurt, and her head doesn't. She stays inside
  the board. If you stand still for the whole attack, you lose about
  18 HP.
- **Annoyed (A').** This comes after you refuse to give her the Flakes.
  Temmie looks smug, and "can't blame a BARK for tryin'..." shows as the
  picture. The SOUL starts on the floor in front of her, and the safe spot
  is on top of her back. She walks faster, pauses less and feints more
  often.
- **The arm (B).** Her arm comes down from her portrait into a 12x12
  board. It moves one cell at a time on the board's 8 px grid, like
  Snake. The arm is a 4 px line drawn with background tiles, so it lines up
  exactly with the grid. The hand (`temmie_attack_4`) glides from cell to
  cell. At every cell it turns toward the SOUL, and it never reverses or
  crosses itself. The hand and the line both hurt. It pulls back when it
  reaches `max_cells`, when it's boxed in, or when the SOUL traces the
  edges and stops near the middle of one.

Every number above is in `content.c` (`tall_params`, `arm_params`,
`tall_boxes`, `tall_leg_x`, `atk_box`).

## Death

At 0 HP everything disappears except the SOUL. It stays frozen, then
cracks (`soul_broken`, with the `SFX_HEART_CRACK` sound), then shatters
into shards that fly up and fall (`SFX_HEART_SHATTER`), and then GAME OVER
appears. The timings and the gravity are the `DEATH_*` values in
`config.h`. The broken heart and the shards are drawn in
`tools/build_sprites.py`, because the art in `assets/` doesn't include
them.

## Defaults for the other open questions

- **Feed with Flakes.** You get a Yes/No prompt. Yes plays "FOOB!!!", then
  "OMG!! humans TOO CUTE", and you win. No starts the annoyed attack.
  Without Flakes, Temmie says "NO!!! so hungr..." and the fight ends with
  her leaving.
- **Talk.** One Talk makes her sparable. Temmie answers with a random line
  from the neutral pool.
- **Attack order.** Each turn picks randomly between TALL and ARM. The
  annoyed variant only comes after the refusal.

The three outcome lines in `content.c` (`out_spared`, `out_fed`,
`out_left`) are placeholder wording and are not from the source text.

## Replacing assets

- **Art.** All the art is in `assets/`. After changing it, run:

  ```bash
  python3 tools/build_sprites.py
  ```

  The script packs the art into `res/sprites.png` and regenerates
  `src/sprite_layout.c/.h`. Each image is cut into 16x16 pieces, empty
  pieces are dropped and identical ones are shared, and it stops if the
  sheet goes over the 512 sprite tiles of VRAM. The current sheet uses 232.
  `make` then converts the sheet with `opensnes-sprite`, so the build
  itself never runs Python. The width of tall Temmie's stretched body is
  `TALL_STRETCH` in the script.
- **Art that's in `assets/` but not used.** `temmie_hurt.png` would only
  appear when you FIGHT, and FIGHT isn't implemented. The Japanese smug
  text isn't used either. The `*_4x.png` files are previews.
- **Sound.** See the next section.

## Sound

The game plays a sound hook (`sound_sfx(SFX_...)`) at every moment that
could make a sound. A hook with no sound assigned stays silent. Here is
every hook, from `src/sound.h`:

| Hook | When | Sound now |
|---|---|---|
| `SFX_MOVE` | a menu cursor moves | placeholder |
| `SFX_SELECT` | a menu choice is confirmed | placeholder |
| `SFX_BACK` | B leaves a sub-menu | none |
| `SFX_DENIED` | MERCY is pressed before Temmie is sparable | none |
| `SFX_BLIP` | narration is typing | placeholder |
| `SFX_TEMMIE_VOICE` | Temmie's speech is typing | placeholder |
| `SFX_SMUG` | the "can't blame a BARK" picture appears | none |
| `SFX_ATTACK_START` | an attack begins | none |
| `SFX_TEMMIE_STEP` | a foot of tall Temmie lands while she walks | none |
| `SFX_ARM_STEP` | the arm moves one cell | none |
| `SFX_ARM_RETRACT` | the arm starts pulling back | none |
| `SFX_HURT` | the SOUL takes damage | placeholder |
| `SFX_HEART_CRACK` | death: the SOUL cracks | placeholder |
| `SFX_HEART_SHATTER` | death: the SOUL shatters | placeholder |
| `SFX_SPARE` | Temmie is spared | placeholder |
| `SFX_EAT` | Temmie eats the Flakes | placeholder |
| `SFX_WIN` | you win by feeding her, or she runs off | none |

There are also music hooks (`sound_bgm`): `BGM_BATTLE` at the start,
`BGM_WIN`, `BGM_LOSE` at GAME OVER, and `BGM_NONE` when you die.

**To give a hook a sound** (the same three steps are in the comment at the
top of `src/sound.c`):

1. Put the sound in `res/` as a WAV file: mono, 16-bit PCM, any sample
   rate, a short one-shot. For example, `res/sfx_step.wav`. Next to it,
   add a settings file `res/sfx_step.wav.toml` (copy any existing
   `res/sfx_*.wav.toml`). It contains:

   ```toml
   tool = "opensnes-sample"

   [encode]
   ```

   When you run `make`, it converts the WAV and writes `res/sfx_step.h`.
2. In `src/sound.c`, add `#include "../res/sfx_step.h"` next to the other
   includes.
3. In `sfx_table` in the same file, fill the hook's row:
   `[SFX_TEMMIE_STEP] = SFX(sfx_step, 90),`. The number is the volume,
   from 0 to 127.

**To replace a sound:** overwrite its WAV file and rebuild. You don't need
to change anything else.

**To add a new hook:** add an id to the enum in `src/sound.h`, call
`sound_sfx(SFX_YOUR_ID);` where the event happens, then do the three steps
above.

**Limits:** the sound driver holds up to 64 samples, in about 58 KB of
APU RAM. To regenerate the placeholder beeps, run
`python3 tools/make_placeholder_sfx.py [names]`. Don't run it once you've
replaced them, because it overwrites the WAVs.

**Music:** `sound_bgm()` doesn't play anything yet. Tracker music needs
the SDK's `snesmod` module, which drives the sound chip itself and plays
the effects too. The comment in `src/sound.c` explains how.

## Not implemented

- FIGHT shows a "not implemented" line.
- ITEM only reports whether you hold the Flakes.
- There is no BGM yet.
- The game stalls for 1 to 2 frames when a box is redrawn between states.
  Attacks run with no lag frames. Sprites go through the SDK's assembly
  `oamDrawMetasprite`, Temmie's portrait sits in fixed OAM slots, and the
  legs and the arm are each drawn in one call.
